Sobre o DevPortfolio

Uma plataforma criada para conectar desenvolvedores e seus projetos em um só lugar.

1

Cadastre seu Perfil

Desenvolvedores podem registrar suas informações, foto, bio, especialidade e redes sociais no painel administrativo.

2

Publique Projetos

Vincule projetos completos informando tecnologias utilizadas, repositórios no GitHub e links de aplicação ativa.

3

Receba Contatos

Recrutadores e clientes visitam os perfis e enviam mensagens diretamente através do formulário de contato.

Tecnologias Utilizadas

Java 25 Spring Boot 4 Angular MySQL TypeScript
